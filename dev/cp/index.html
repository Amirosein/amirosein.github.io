APPLE PLATFORMS · HPC

ClusterPilot

HPC cluster management across Apple devices.

An application for managing HPC clusters, enabling users to monitor and submit jobs, manage cluster files, configure batch scripts, and handle essential cluster operations from iPhone, iPad, and Mac.

Swift SwiftUI SLURM REST API PHP Linux
01

OVERVIEW

HPC workflows,
in one interface.

ClusterPilot brings common HPC workflows into a native interface, providing access to cluster jobs, files, terminals, and batch configuration without relying entirely on a traditional command-line workflow.

01 Jobs

Monitor running and pending SLURM jobs and manage your jobs.

02 Submit Jobs

Configure SLURM batch parameters and submit jobs directly.

03 Files

Browse directories and access files stored on the cluster.

04 Terminal

Access the cluster terminal when direct command-line interaction is needed.

02

JOB MANAGEMENT

Monitor jobs
from anywhere.

View running and pending SLURM jobs, track job IDs and runtime, switch between all jobs and your own jobs, and cancel jobs when needed.

JOB CONTROL

Manage submitted workloads.

ClusterPilot provides direct access to job state and basic job control operations through the SLURM interface.
